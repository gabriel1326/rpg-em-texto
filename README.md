## 🐉 Sobre o Jogo

Um **RPG de texto com mundo aberto** inspirado em **D&D 5e**, rodando direto no terminal. Explore masmorras, enfrente inimigos, suba de nível, colete itens e embarque em quests épicas — tudo com texto e imaginação.

> *"A aventura começa com um único passo... ou com um único comando."*

---

## ⚔️ Funcionalidades

| 🎮 Jogabilidade | ⚙️ Sistema |
|:---|:---|
| Mundo aberto para explorar | Salvar e carregar partidas |
| Batalhas por turno | Sistema de XP e níveis |
| Magias e habilidades | Inventário completo |
| NPCs e diálogos | Sistema de quests |
| Itens, armas e armaduras | Conquistas desbloqueáveis |
| Lojas e comércio | Mapa do mundo |

## 🎚️ Dificuldades

| Nível | Encontros | XP | Inimigos |
|:---:|:---:|:---:|:---:|
| 🟢 **Fácil** | Raros | +50% | Mais fracos |
| 🟡 **Normal** | Balanceado | Normal | Normal |
| 🔴 **Difícil** | Frequentes | -15% | Mais fortes |
| 💀 **Extremo** | Constantes | -35% | Muito mais fortes |

---

## 🕹️ Modos de Controle

**Modo Numérico** — Recomendado para iniciantes. Navegue por menus com números, sem precisar digitar nada além de `1`, `2`, `3`...

**Modo Texto** — Para jogadores experientes. Digite comandos livremente em português:
```
> ir norte
> falar Ferro
> usar poção
> atacar goblin
> equipar espada longa
```

## 🚀 Como Jogar

### ▶️ Executável (mais fácil)
Baixe o arquivo `D&D.exe` na seção [Releases](../../releases) e execute diretamente. Não precisa instalar nada!

### 🐍 Com Python
```bash
# Clone o repositório
git clone https://github.com/gabriel1326/rpg-em-texto.git

# Entre na pasta
cd rpg-em-texto

# Rode o jogo
python D_D.py
```

> Requer **Python 3.7+**
